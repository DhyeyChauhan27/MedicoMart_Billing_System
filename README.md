# MedicoMart – Pharmacy Billing & Management System

## 📌 Project Overview

MedicoMart is a desktop-based Pharmacy Billing and Management System developed to simplify and manage daily pharmacy operations. The application helps pharmacy administrators manage medicine stock, maintain customer records, generate purchase bills, and monitor sales activities efficiently.

The system provides an easy-to-use interface for managing medicine inventory, processing customer bills, searching records, and generating sales reports. It reduces manual paperwork, improves billing accuracy, and makes pharmacy management more organized and efficient.

## 🚀 Key Features

- **Dashboard:** Provides easy access to different modules of the application.
- **Medicine Stock Management:** Add, update, delete, search, and manage medicine stock details.
- **Customer Management:** Maintain and manage customer information.
- **Billing Management:** Generate customer bills based on purchased medicines.
- **Bill Search:** Search and retrieve previously generated bills.
- **Bill Printing:** Generate and print customer invoices.
- **Sales Reports:** View and analyze sales records for better business management.
- **Database Management:** Store and retrieve medicine, customer, stock, and billing information.

## 🛠️ Technologies Used

- **Programming Language:** C#
- **Development Environment:** Microsoft Visual Studio 2010
- **Database:** Microsoft Access
- **Database Connectivity:** ADO.NET
- **Application Type:** Desktop Application

## 💡 Project Objectives

- To simplify pharmacy stock and inventory management.
- To automate the medicine billing process.
- To maintain accurate customer and sales records.
- To reduce manual work and billing errors.
- To generate sales reports for business analysis.
